# LabTrack Mobile Frontend (Expo / React Native)

This is the mobile application client for **LabTrack**, built with React Native and Expo Router.

For comprehensive system documentation, architecture diagrams, and API guides, refer to the [Root README.md](../README.md).

## Development Commands

```bash
# Start development server
npm run start

# Run on Android emulator
npm run android

# Run in Web browser
npm run web

# TypeScript typecheck
npx tsc --noEmit
```
